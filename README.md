## Como executar:
No terminal rode

`git clone https://github.com/Joao-PCruzz/super-mini-flight-simulator.git`

`cd super-mini-flight-simulator`
* Caso esteja usando windows:
    
    `make simulador_windows`
* Caso esteja usando linux:
    
    `make simulador_linux`

`./bin/simulador <raio_terra> <x_sol> <y_sol> <z_sol>`
