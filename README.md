## Como executar:
No terminal rode

`git clone https://github.com/Joao-PCruzz/super-mini-flight-simulator.git`

`cd super-mini-flight-simulator`
* Tanto para Windows quanto para Linux:
    
    `make run ARGS="<raio_terra> <x_sol> <y_sol> <z_sol>"`

    ou

    `make run` 

    No caso de utilizar somente o `make run`, serão as coordenadas Default: 1.0, 0.0, 0.0, 5.0
